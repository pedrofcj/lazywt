# Design history

These implementation plans and design specs were written while this tool was
named **junktree**, and were carried over verbatim when `lazywt` became the
canonical repository.

They are dated historical records, so the old name has deliberately **not** been
rewritten inside them — a document titled "junktree v2.0 Design Spec" and dated
2026-04-02 should keep saying that. Read `junktree` as `lazywt` throughout.

The original repository (`github.com/pedrofcj/junktree`, 343 commits, plus a full
`.planning/` GSD history) is archived and remains available for provenance.
